# Ежедневный запуск /zylo-short без тебя

Цель: каждый день в 16:30 (Asia/Jerusalem) запускается `/zylo-short`, видео выходит в 17:00
(скрипт ставит `publishAt` = 17:00 по Израилю, так что точное время старта не критично).

## Вариант A — запланированная задача Claude Code в облаке (рекомендую)
Запускается в таком же облачном контейнере, как этот, по расписанию `CRON_TZ=Asia/Jerusalem 30 16 * * *`.

Нужно:
1. Приватный GitHub-репозиторий с этим проектом (`zylo-studio`) — контейнер каждый раз клонирует его заново.
2. Облачное окружение с **Network access = Full** (или нужные домены) и переменными
   `YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_REFRESH_TOKEN`.
3. Setup script окружения: `bash scripts/setup.sh` (ставит модель голоса, Python и Remotion, ~2–3 мин).

Плюсы: ноутбук не нужен; часовой пояс и переход на летнее время учитываются (`CRON_TZ`); я сам вижу ошибки
и могу их чинить в следующем запуске; итог приходит уведомлением.
Минусы: расходует лимиты твоего плана Claude; при сбое облака день может быть пропущен (видно в log.md).

## Вариант B — GitHub Actions + `claude -p "/zylo-short"`
Workflow по cron на runner'е GitHub (`ubuntu-latest`), шаги: checkout → `scripts/setup.sh` →
`npx @anthropic-ai/claude-code -p "/zylo-short" --permission-mode acceptEdits` → push.

Нужно: секреты `ANTHROPIC_API_KEY` (оплата по API отдельно от подписки) + три `YT_*`.
Плюсы: полностью твоя инфраструктура, логи каждого запуска в Actions.
Минусы: GitHub cron только в UTC — при переходе Израиля на летнее/зимнее время нужно менять строку
(14:30 UTC зимой / 13:30 UTC летом) или ставить два cron и проверять час в скрипте; запуски по cron
часто задерживаются на 5–30 мин; платный API; 2 000 бесплатных минут/мес для приватных репо (нам ~450).

## Вариант C — cron / launchd на твоём компьютере
`30 16 * * * cd ~/zylo-studio && claude -p "/zylo-short" --permission-mode acceptEdits >> logs/cron.log 2>&1`
(на Mac — launchd plist с `StartCalendarInterval` Hour=16 Minute=30).
Плюсы: проще всего, работает на подписке, сеть без ограничений.
Минусы: компьютер должен быть включён и не спать; закрытый ноутбук = пропущенный день.

## Что нужно для работы без открытого ноутбука
Только A или B: репозиторий на GitHub, OAuth-токен YouTube в секретах окружения, приложение OAuth в статусе
**In production** (иначе токен истекает через 7 дней), сеть окружения с доступом к генераторам картинок.
